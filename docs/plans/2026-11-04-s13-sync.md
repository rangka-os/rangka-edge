# S13 Edge Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First cut of rangka-edge: a durable local queue with idempotency keys, a runner that pushes it with backoff, an `edge-sync/v1` client, an in-repo kernel stub, and a CLI to register, enqueue, show status and flush.

**Architecture:** `internal/queue` is an append-only, fsynced log file (one CRC-checked JSON record per line) replayed into memory on open. `internal/edgesync` holds the protocol types, the HTTP client and `kernelstub` (an `http.Handler` that follows contract 0006). `internal/runner` drains the queue through a `Pusher` with exponential backoff. `cmd/rangka-edge` wires them together.

**Tech Stack:** Go 1.24, standard library only (no cgo, no third-party modules).

**Spec:** `rangka-os/docs/contracts/0006-edge-sync.md` (PR rangka-os/rangka-os#31, branch `pilot/s13-contract`), building on `0003-edge-and-devices.md`; program plan `rangka-os/docs/superpowers/plans/2026-11-03-pilot-program.md` stream S13.

## Global Constraints

- Go 1.24 (`go.mod` stays `go 1.24`), standard library only, `CGO_ENABLED=0` builds.
- Deterministic only: no LLM in the device data path. Every queued item has an idempotency key. Offline first.
- Code, comments, docs in English. Operator CLI output in English; cashier UI text (none yet) in Bahasa Indonesia.
- Protocol (0006): base path `/api/v1/edge`, header `Rangka-Edge-Sync: v1`, bearer device token, error body `{"error":{"code","message"}}`.
- Default key: `<device_id>:<seq>` with seq zero-padded to 12 digits (`dev_ab:000000000042`); keys at most 200 chars.
- Statuses `accepted`, `duplicate` ack; `rejected` (codes `unknown_kind`, `payload_invalid`, `key_conflict`) goes to dead-letter and is never retried automatically.
- Retry on network error, timeout, 5xx, 429: backoff 1 s doubling to 5 min, ±20 % jitter, `Retry-After` honoured. `401 device_revoked` stops syncing, queue kept.
- v1 kinds: `sale.recorded`, `sale.voided`, `stock.counted`, `print.done`, `print.failed`, `device.read`.
- `go vet ./... && go test ./...` green; also `gofmt -l .` empty.

## Review Focus

1. Power loss mid-append (torn last line): the queue opens, keeps every complete record, truncates the tail. → Task 1 `TestOpenTruncatesTornTail`.
2. Kernel stored a batch but the response was lost: the retry gets `duplicate`, the stub holds one copy, the queue acks once. → Task 3 `TestFlushAfterLostResponse`.
3. Same key enqueued again with a different payload: `ErrKeyConflict`, original kept. → Task 1 `TestEnqueueSameKeyDifferentPayload`.
4. One rejected event in a batch: the others are acked, the rejected one is dead, flush ends. → Task 3 `TestFlushRejectedGoesDead`.
5. Two processes opening the same queue: the second gets `ErrLocked` (unix). → Task 1 `TestOpenTwiceLocked`.

### Task 1: Durable queue

**Files:** Create `internal/queue/{queue.go,log.go,lock_unix.go,lock_other.go,queue_test.go}`; keep the package doc.

**Interfaces (produces):**
```go
var ErrKeyConflict, ErrLocked, ErrCorrupt, ErrNotFound error
type State string // "pending" | "done" | "dead"
type Item struct {
    Key, Kind, Actor string; Seq int64
    OccurredAt, EnqueuedAt time.Time
    Payload json.RawMessage
    State State; Ref, Code, Message string // Ref on done; Code/Message on dead
}
type Options struct{ DeviceID string; Now func() time.Time } // Now defaults to time.Now
type NewItem struct{ Key, Kind, Actor string; OccurredAt time.Time; Payload json.RawMessage }
type Stats struct{ Pending, Dead, Done int; OldestPendingAt time.Time; LastSeq int64 }
func Open(dir string, opt Options) (*Queue, error)
func (q *Queue) Enqueue(n NewItem) (it Item, added bool, err error)
func (q *Queue) Pending(limit int) []Item   // seq order
func (q *Queue) DeadItems() []Item          // seq order
func (q *Queue) Get(key string) (Item, bool)
func (q *Queue) Ack(key, ref string) error  // pending→done; already done: nil; unknown: ErrNotFound
func (q *Queue) Dead(key, code, message string) error // pending→dead
func (q *Queue) Stats() Stats
func (q *Queue) Close() error
```
- Files in `dir`: `queue.log`, `queue.lock`. Records: `{"op":"put","item":{…}}`, `{"op":"ack","key","ref","at"}`, `{"op":"dead","key","code","message","at"}`, `{"op":"done","key","seq","at"}` (compacted ack). Every append is one `Write` + `File.Sync`.
- Enqueue: empty `Key` → `<DeviceID>:<seq %012d>`; `Seq` = last seq + 1 (persisted in records, so it survives restart); `Kind` required; `OccurredAt` zero → `Now()`. Existing key with byte-identical payload (compare after `json.Compact`) and kind → return stored item, `added=false`, no write. Existing key otherwise → `ErrKeyConflict`. Key > 200 chars → error. Done keys are remembered after compaction.
- Replay: a bad last line (CRC mismatch, bad JSON or missing `\n`) is truncated; a bad line followed by good lines → `ErrCorrupt`.
- Compaction on `Open` when done records ≥ 1000 and more than half the records: write `queue.log.tmp` (pending + dead as `put`/`dead`, done as `done`, dropping done older than 400 days), fsync, rename, fsync dir.
- Mutex around all methods.

### Task 3: Runner with backoff

**Files:** `internal/runner/{runner.go,backoff.go,runner_test.go}`; update the package doc (runs the edge's loops: sync push now, device connectors later).

**Interfaces:**
- Consumes: `queue.Queue` (`Pending`, `Ack`, `Dead`, `Stats`), `edgesync.Event`, `edgesync.Result`, `edgesync.Retryable`, `edgesync.ErrRevoked`, `HTTPError.RetryAfter`.
- Produces:
```go
type Pusher interface{ Push(ctx context.Context, events []edgesync.Event) ([]edgesync.Result, error) }
type Backoff struct{ Min, Max time.Duration; Jitter float64; Rand func() float64 } // zero → 1s, 5m, 0.2, math/rand/v2
func (b Backoff) Delay(attempt int, retryAfter time.Duration) time.Duration // attempt 0 → Min; max(…, retryAfter); capped at Max before jitter
type Report struct{ Pushed, Duplicates, Rejected int }
type Runner struct {
    Queue *queue.Queue; Pusher Pusher; BatchSize int // 0 → 100
    Backoff Backoff; Idle time.Duration               // 0 → 5s, poll interval when empty
    Sleep func(ctx context.Context, d time.Duration) error // nil → timer honouring ctx
    Logf func(format string, args ...any)
}
func (r *Runner) Flush(ctx context.Context) (Report, error) // one pass until queue empty; first push error returned as-is
func (r *Runner) Run(ctx context.Context) error            // loop: Flush; retryable → Sleep(Delay(n)) and n++; success → n=0, Sleep(Idle); ErrRevoked or other non-retryable → return it; ctx done → ctx.Err()
```
- Flush maps `Item` → `Event` (same key, kind, seq, occurred_at, actor, payload), batches `Pending(BatchSize)`, then per result: accepted → `Ack(key, ref)`; duplicate → `Ack(key, ref)`; rejected → `Dead(key, code, message)`. A result for an unknown key is an error.
- Non-retryable `HTTPError` other than revoked (e.g. 400) is returned from `Run`; the queue is untouched.
